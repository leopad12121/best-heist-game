Velvet Vault — a top-down museum heist game. Cross one museum floor past three patrolling guards and two sweeping cameras, steal the Starlight Sapphire from the vault, and slip out the green exit before the alarm meter fills. Tools cost coins: Smoke breaks line of sight, EMP freezes the cameras, Disguise fools the guards. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, keyboard (WASD/arrows, 1/2/3 for tools, Space to use) and mouse (click a tool button or anywhere to use the picked tool).
