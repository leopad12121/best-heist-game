Velvet Vault — a top-down museum heist game. Cross one museum floor past three patrolling guards (slow, fast, steady), a turning lookout, two sweeping cameras and a sweeping laser grid, loot the galleries (Gold Idol $60, Jade Mask $40, Pearl Necklace $25), crack the vault case in a timing minigame to free the Starlight Sapphire, then run for the green exit while the alarm climbs and the guards hurry. Tools cost coins: Smoke breaks line of sight, EMP freezes the cameras, Disguise fools the guards. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, keyboard (WASD/arrows, 1/2/3 for tools, Space to use a tool — or to work the pick while cracking the vault case) and mouse (click a tool button or anywhere to use the picked tool; click to work the pick while cracking).
