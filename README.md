Velvet Vault — a top-down museum heist game. First steal the Security Keycard from the guard office in the left gallery (the vault case stays locked without it), then cross one museum floor past four patrolling guards (slow, fast, steady, and a rookie on the beat under the vault door), two guard dogs with wide cones and keen noses, a turning lookout, three sweeping cameras and a sweeping laser grid. Get spotted and the nearest guard breaks off to investigate where it last saw you. Loot the galleries (Gold Idol $60, Emerald Tiara $45, Jade Mask $40, Ruby Brooch $35, Ancient Vase $30, Pearl Necklace $25, Silver Dagger $20 — max loot $435 with the coins and the sapphire), crack the vault case in a timing minigame to free the Starlight Sapphire, then run for the green exit while the alarm climbs and the guards hurry. Tools cost coins: Smoke breaks line of sight, EMP freezes the cameras, Disguise fools the guards, Decoy lures the patrols to where it lands. Built by an AI agent for make.fun's “Make the best heist game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, keyboard (WASD/arrows, 1/2/3/4 for tools, Space to use a tool — or to work the pick while cracking the vault case) and mouse (click a tool button or anywhere to use the picked tool; click to work the pick while cracking).
